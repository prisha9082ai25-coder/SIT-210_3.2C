
Task 5.1GUI – Raspberry Pi GUI LED Control

This project uses Python and Tkinter to create a simple GUI
for controlling three LEDs connected to a Raspberry Pi.

The three LEDs represent:
- Living Room – GPIO 17
- Bathroom – GPIO 27
- Closet – GPIO 22

The user can select a room using radio buttons. The selected
LED turns ON while the other LEDs remain OFF.

The Exit button turns OFF all LEDs and closes the GUI.

Hardware:
- Raspberry Pi
- Breadboard
- 3 LEDs
- 3 × 220Ω/330Ω resistors
- Jumper wires

Software:
- Raspberry Pi OS
- Python 3
- Tkinter
- GPIO Zero
