# Smart Automatic Lighting System

An Arduino Nano-based smart lighting system that automatically turns ON LEDs when motion is detected in a dark environment. It uses a PIR sensor, BH1750 light sensor, and a push button for manual control.

## Features

- Motion detection using PIR sensor
- Automatic lighting in darkness
- Manual ON/OFF button
- Hardware interrupt support
- Energy-efficient operation

## Components

- Arduino Nano
- PIR Motion Sensor
- BH1750 Light Sensor
- 2 LEDs
- 2 × 220Ω Resistors
- Push Button
- Breadboard & Jumper Wires
